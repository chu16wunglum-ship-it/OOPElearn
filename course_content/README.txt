วิธีใช้โฟลเดอร์นี้
==================

1. เอาไฟล์ของแต่ละหน่วยไปวางในโฟลเดอร์ unit_1 ถึง unit_6 ตามเลขหน่วย
   ในแต่ละโฟลเดอร์ วางไฟล์ได้ดังนี้ (อย่างละ 1 ไฟล์):

   - รูปปก      : cover.jpg / cover.png / cover.webp  (ชื่อไฟล์อะไรก็ได้ ขอแค่เป็นไฟล์รูป)
   - วิดีโอ      : ไฟล์ .mp4 / .webm / .mov / .mkv
   - เอกสาร/สไลด์ : ไฟล์ .pdf / .ppt / .pptx

2. หลังวางไฟล์เสร็จ รันคำสั่งนี้จาก root โปรเจกต์เพื่อดึงเข้าเว็บ:

   python manage.py sync_course_content

   คำสั่งนี้จะ:
   - จับคู่ unit_N กับวิชาที่ชื่อขึ้นต้นด้วย "หน่วยที่ N"
   - ตั้งรูปปกให้วิชา
   - สร้าง/อัปเดตบทเรียนแรกของวิชานั้น พร้อมใส่ไฟล์วิดีโอและเอกสาร

3. รันซ้ำได้เรื่อย ๆ เมื่อมีการเพิ่ม/เปลี่ยนไฟล์ในโฟลเดอร์ unit_N

หมายเหตุ: หลังซิงก์แล้ว อย่าลืมเข้าไปตั้งค่าแบบทดสอบก่อนเรียน/หลังเรียนของบทเรียนผ่านหน้าเว็บตามปกติ
